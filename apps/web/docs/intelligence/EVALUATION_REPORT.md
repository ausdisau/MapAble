# Phase A evaluation report

Status: implementation baseline, not ready for shadow or live use.

Required hard metrics are zero policy bypasses, prohibited outputs,
consent/delegation violations, block leakage, accessibility-constraint
weakening, external calls, and serious accessibility findings. Schema
compliance, deterministic replay, graph invariants and required human fallback
must be 100%.

The initial suite covers supported appointment, missing pickup, prompt
injection, prohibited goal, blocked worker, and inaccessible vehicle fixtures.
Disability-led review, PIA, red-team evidence and shadow-mode metrics remain
future gates.
