# Access Intelligence Next — Architecture

## Hybrid Living Access Fabric

- PostgreSQL canonical writers remain authoritative (`AccessPlace`, indoor floor plans, Transport, Care, Jobs, Billing).
- Access Intelligence Next owns deterministic compilers and a **read projection** (Living Access Graph).
- Models may draft and explain; deterministic services evaluate constraints; participants decide; authorised humans retain clinical/legal/emergency authority; application services perform approved writes.

## Layers (Wave 0–2 scope)

1. **Sense** — fixture observations only in this PR
2. **Normalise** — ontology mapping
3. **Understand** — synthetic Harbour graph
4. **Fit** — Personal Access Compiler + AQL
5. **Prove** — proof-carrying results
6. **Govern** — feature flags default off; permanent deny flags for scores / diagnosis / AI publish / AI execute

Later waves add temporal expiry, change review, Continuity recovery fit, Vision candidates, and sector twins.
