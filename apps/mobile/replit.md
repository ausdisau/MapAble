# Replit Agent context — MapAble + AdaptAble Home

This is a disability-led, accessibility-first React Native + Expo prototype for the Independence Suite.

Product rules:
- Keep the person in control. Indy proposes bounded actions and requires explicit approval for consequential actions.
- Do not claim live emergency dispatch, support-worker contact, smart-home control, live MapAble routing, live location sharing, AccessiBooks catalogue access, disability-news ingestion, analytics, or AI-provider connectivity unless a real verified adapter exists.
- Treat skipped tasks as user choices, not failures.
- Make consent understandable: who can use data, what data, why, for how long, and when it was last used.
- Preserve scalable text, large controls, accessible names/roles, safe areas, reduced-motion support, high contrast, and non-colour-only state communication.

Engineering rules:
- Expo SDK 57, React Native 0.86, React 19.
- React Navigation 7 static API.
- Keep secrets in Replit Secrets, never in the repository.
- Measure performance before adding memoization or optimisation libraries.

Current prototype areas: Today, AdaptAble Home, Indy, MapAble, AccessiBooks, News & Advocacy, My Access, Permissions, Activity, and Support.
