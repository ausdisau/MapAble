# Build, Partner or Defer Matrix

**Status:** strategy documentation — decisions require human approval before external claims  
**Legal note:** not definitive legal, insurance, audit or registration advice.

## Build now

MapAble should own these because they form the defensible participant journey and
already have canonical modules on main.

| Capability | Why MapAble owns it | Minimum viable | Pilot |
|------------|---------------------|----------------|-------|
| Participant Passport | Authority and portability vs provider-owned profiles | Field disclosure + export + ack | Flagged internal |
| Care and Transport completion | Transaction parity with incumbents, on canonical SoTs | Persistent quotes; recurring Care; agreements | Controlled pilot |
| Companion | Offline Visit Pack without smartphone-only essential path | Encrypted store + revoke | Controlled pilot |
| Provider Operations | Read-only attention SaaS without second writer | Attention queue + deep links | One provider |
| AccessCast pilot | Personalised environmental outlook (synthetic→venue) | Harbour synthetic + widget path | Venue partner |
| Workforce readiness | Reasons-only readiness; no scores | Deterministic evaluate API | With Care assign |
| Continuity / recovery | Failure → participant choice → receipt | Care cancel ≠ Transport cancel | Starting Work |
| Evidence-to-payment | Integrity advantage | ServiceRecord → invoice | Billing Centre |
| Participant outcomes | Outcome ≠ payment | Review receipt | Starting Work |

## Partner now

Integration boundary: agreement, evidence, mission coordination — not clinical SoT.

| Capability | Integration boundary | MapAble does not |
|------------|----------------------|------------------|
| SIL / SDA | Partner delivers; MapAble coordinates journey refs | Claim property/clinical ownership |
| Complex clinical supports | Referral + Passport disclosure | Clinical decisions / AI approval |
| Allied health | Booking + evidence handoff | Prescribe therapy |
| Behaviour support | Partner clinical governance | Substitute PBS |
| Professional AT assessment | Assessment ref + equipment lifecycle links | Claim clinical suitability |
| Accessible vehicle fleets | Eligibility + quote + evidence | Own fleet ops initially |
| Equipment repair | Repair partner + Continuity mission | Guarantee repair SLA alone |
| Emergency response | Direct users to 000 / local emergency | Automate emergency dispatch |
| Independent clinical review | Appeals / safeguarding partner | Internal “independent” review without separation |

## Defer

| Item | Trigger for reconsideration |
|------|-----------------------------|
| Broad national worker-marketplace launch | Regional liquidity + human ops SLOs proven |
| Large property portfolio | Separate registered entity + capital |
| Ventilator / tracheostomy support | Clinical governance + registration + workforce |
| Autonomous assignment | Permanent product prohibition unless law/policy changes and human override remains |
| Autonomous claims | Permanent prohibition on AI claim approval |
| Direct NDIA integration | Formal NDIA authorisation + adapter gates |
| Plan management | Registration + conflict-of-interest resolution |
| National expansion | Regional operations proven (providers, transport redundancy, Q&S exercises) |
