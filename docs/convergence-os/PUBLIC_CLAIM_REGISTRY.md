# Public Claim Registry

Machine seed: `lib/platform/convergence-os/seed/public-claims.ts`.

## Rule

Feature flags and documentation are **not** evidence of production readiness.

A public claim is allowed only when maturity is `limited_release`, `production_ready`, or `generally_available` **and** evidence gates pass.

## Current prohibitions (examples)

- Living Access Fabric as live personal accessibility truth
- Live NDIA submission
- Guaranteed transport arrival
- Academy completion as competency
- Automatic / AI worker assignment
- Production Companion / secure offline claims before encrypted store proven
- Live Xero / automatic claim approval
- AURA deciding payments, assignment, or safeguarding
- “Route is safe” without evidence versioning

## Allowed honest wording

Use: synthetic demo, shadow evaluation, scaffold, internal alpha, adapters disabled, readiness reasons, estimate ≠ arrival, unknown remains unknown.
