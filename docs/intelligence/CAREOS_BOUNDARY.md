# CareOS boundary

CareOS is the participant-facing MapAble intelligence layer and may read
authorised operational information through governed tools. Phase A Mainframe is
a separate synthetic evaluation kernel. It must not import CareOS context
builders, tools, Life Twin services, audit services, Prisma models, dashboard
components, or participant routes.

Future integration requires an approved adapter interface, privacy review,
shadow-mode safety case, and a new implementation plan.
