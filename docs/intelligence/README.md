# MapAble Core Intelligence Mainframe — Phase A

Phase A is an isolated synthetic-only evaluation kernel. It has no production
data, Prisma access, live adapters, model-provider calls, execution tools, or
participant-facing workflow. It evaluates a bounded Care and Transport
appointment proposal and always remains at recommendation authority or below.

CareOS remains MapAble's existing participant-facing read-only layer. This
mainframe sandbox does not alter CareOS behaviour.
