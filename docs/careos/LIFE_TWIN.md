# Participant Life Twin

The Life Twin stores participant-confirmed communication, accessibility,
mobility, support, worker, cultural, language, routine, goal, trusted-circle,
delegation, contingency and remembered CareOS preferences. Participants can
inspect, update and soft-delete optional memory.

Operational and clinical records are not general AI memory. Persistent memory
is disabled unless `MAPABLE_CAREOS_MEMORY_ENABLED=true`; no inferred profile or
model-generated value is marked verified.
