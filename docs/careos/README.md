# CareOS Foundation

CareOS is MapAble's participant-controlled Care and Support Intelligence layer.
It helps participants coordinate care, accessible transport, appointments and
access evidence. AI may propose; participants decide; deterministic MapAble
services execute only in a future, separately approved action phase.

This increment is read-only and limited to L2 recommendations. It does not
make bookings, submit claims, release payments, provide clinical advice, or
replace qualified professionals.

See the companion documents for architecture, consent, privacy, accessibility,
testing, environment setup, rollback, and explicitly deferred next phases.
