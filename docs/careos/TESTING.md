# Testing

Run `pnpm type-check`, `pnpm lint`, `pnpm test`, `pnpm build`, and
`pnpm prisma validate`. CareOS tests cover policy classification, feature
flags, redaction, registry validation, and the no-booking/non-AI path.

Before enabling CareOS, manually verify a keyboard-only request, focus and
live-region announcements, 200% zoom, reduced motion, consent refusal,
missing pickup handling, no compatible worker, no accessible transport and
standard Care/Transport links.
