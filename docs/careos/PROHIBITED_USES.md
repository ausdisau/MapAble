# Prohibited uses

Policy code blocks eligibility or funding decisions, diagnoses, treatment or
symptom conclusions, capacity decisions, restrictive-practice recommendations,
emotion/deception recognition, disability/risk scoring, employment or worker
discipline decisions, complaint resolution, emergency interpretation,
invoice/payment/claim automation, unapproved disclosure, direct agent database
writes, and hidden cross-module data reuse.

These capabilities are absent from the tool registry and rejected by policy;
they are not merely prompt instructions.
